## Nestjs 应用的生命周期

一个请求的完整流程闭环如下：

客户端 Client 发起 Request -> 中间件 Middleware -> 守卫 Guard -> 拦截器 Inceptor -> 管道 Pipe -> 控制器 Controller -> 服务 Service -> 拦截器 Inceptor -> 过滤器 Filter -> 客户端收到 Response


## 核心概念笔记

Controllers 控制器 - 处理请求
Services 服务 - 数据访问与核心逻辑处理
Modules 模块 - 组合所有的逻辑代码
Pipe 管道 - 校验请求数据
Filter 过滤器 - 处理请求时的错误
Guard 守卫 - 鉴权与认证相关
Intercorptor 拦截器 - 给请求与响应加入额外的逻辑
Repository 存储库 - 处理在数据中相关的数据
